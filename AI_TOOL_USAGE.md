# AI Tool Usage

AI coding tools were used during development as development assistants rather than as replacements for engineering decisions.

## Tools Used

### Antigravity IDE / AI Coding Assistant

Used to:

- Inspect the existing codebase
- Trace application architecture
- Implement and modify backend/frontend components
- Debug deployment issues
- Run and interpret tests
- Diagnose configuration and integration problems

### OpenAI / ChatGPT

Used for:

- Architecture discussion
- Debugging and reasoning through implementation issues
- Reviewing errors and logs
- Planning deployment and integration steps
- Refining prompts and technical documentation

### GitHub

Used for source control and deployment integration.

## Development Approach

AI-generated suggestions were reviewed and tested against the actual application.

Final implementation decisions, testing, configuration, and deployment verification were performed against the working project rather than relying solely on generated code.
